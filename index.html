📲 홈 화면에 바로가기 추가하기

아이폰 / 아이패드에서는 사파리 브라우저에서 아래 순서대로 쉽게 추가할 수 있습니다:

  1. 사파리(Safari) 화면 하단(또는 상단)의 공유 버튼( )을 누릅니다.
  2. 메뉴를 내려 [홈 화면에 추가]를 누릅니다.
  3. 우측 상단 [추가]를 누르면 바탕화면에 단축 아이콘이 생성됩니다!

내 웹사이트에 적용하는 방법
① 사진 선택/붙여넣기

③ ZIP 파일 다운로드
④ 웹 루트에 파일 업로드
⑤ index.html 태그 삽입
💡 웹 적용 팁: 다운로드받은 ZIP 파일 안의 웹에 넣을 설정.txt 내용을 복사하여 웹사이트 index.html의 </head> 직전에 추가해 주시면 됩니다.
